# 🎈 热气球锦标赛 (Balloon Rally)

一个热气球比赛游戏: 在规定时间里飞到目标区上空, 把标志袋投到离目标中心越近越好。
气球**不能转向** —— 只能靠升降在不同高度找到吹向目标的风。

- 渲染: **WebGL2**(地形/气球/高压线/测风气球, 手写着色器, 无第三方库)
- 物理与界面: **TypeScript**(理想气体浮力 + 集总热容 + 分层风廓线 + 逆温层)
- 物理精度: 爬升率与续航经 `npm run validate` 对照飞行手册经验值验证, 偏差 < 15%(见 [PHYSICS.md](PHYSICS.md))

## 运行

```bash
npm install
npm run build       # 打包 dist/bundle.js
npm start           # http://localhost:8000
```

## 验证物理模型

```bash
npm run validate    # 物理对标(±15% 判据) + 赛区数据检查
npm run typecheck
```

## 玩法

1. **赛区选择页**: 三个虚构赛区(晨雾河谷 / 丘陵麦田 / 湖畔平原), 各有不同的地形、逆温层和分层风
2. **飞行页**: 按住 ↑ 点火(加热有滞后, 升降惯性大), ↓ 打开放气阀快速下降; 清晨近地面风小、上层风大, 各层风向不同
3. **测风气球 (P)**: 释放后随风漂移上升, 在**风廓线分析页 (T)** 上逐层揭示风向风速 —— 先探风, 再决定在哪个高度飘多久
4. **投袋 (空格)**: 接近目标时降低高度投下标志袋, 标志袋下落中随各层风漂移, 落点距目标越近分越高(最高 1000 分)
5. **出局条件**: 触碰高压线立即出局; 燃料耗尽只能迫降; 超时/飞出赛区按已投袋计分

### 操作

| 按键 | 功能 |
|---|---|
| ↑ (按住) | 燃烧器加热 |
| ↓ (按住) | 放气阀 |
| ← / → | 旋转视角(拖拽/滚轮也可) |
| P | 放测风气球 |
| 空格 | 投标志袋 |
| T | 风廓线分析页(打开时计时暂停) |
| 1 / 2 / 3 | 时间倍速 ×1 / ×4 / ×8 |

## 代码结构

```
src/
  atmosphere.ts  ISA 大气 + 逆温层(静力学积分)
  balloon.ts     热力学/飞行动力学(理想气体浮力、热惯性、附加质量)
  wind.ts        分层风廓线 + 湍流
  venues.ts      三个赛区的地形/风/高压线/目标(虚构)
  entities.ts    测风气球、标志袋
  renderer.ts    WebGL2 渲染器与网格构建
  game.ts        飞行主循环、输入、碰撞、计分
  ui.ts          页面切换、风廓线绘制、成绩页
test/
  validate.ts    物理模型 vs 飞行手册经验值(±15%)
  sanity.ts      赛区数据健全性
```
